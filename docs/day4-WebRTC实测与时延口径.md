# Day4 WebRTC 实测与首字时延口径

> 状态：2026-11-13 实测。对应指南第 7.4、7.5 节与第 13 章风险对策。

## 一、结论先行

**WebRTC 在本机可用，按原方案上 aiortc，不必切 WS 备选。**

指南第 13 章把"aiortc 装不上 / 握手折腾超过 2 天"列为中概率风险，要求 Day4 下午就决策。实测下来这道关过了：

| 项目 | 实测值 |
|---|---|
| 库版本 | aiortc 1.16.0，av 19.0.2，Python 3.12.10（Apple Silicon） |
| 连接建立（本机回环，无外网） | 380 ~ 454 ms，三次实测 |
| 音频帧收发 | 发 30 帧收 25 帧、发 50 帧收 45 帧，收帧率 83% ~ 90% |
| 帧到帧单程间隔中位数 | 约 139 ~ 141 ms |

**关于最后一个数字要特别说明**：这是"发送端产出这一帧"到"接收端从轨道里取到这一帧"的间隔，里面包含 aiortc 接收端的抖动缓冲（jitter buffer），**不等于网络单向延迟**，也不能拿去当"首字时延"交差。真实首字时延统一按下面的口径算。

收帧率不到 100% 属正常：发送端发完就停，接收端随之结束，首尾各丢几帧是收尾噪声，不是丢包。

## 二、决策与备选

- **主线**：按第 7.4 节做，浏览器 PeerConnection ↔ aiortc，信令走 `/ws/control`，音频走 RTP 轨道。
- **备选仍保留**：WS 纯文本信道传二进制音频帧（第 7.3 节方案）。协议不变，只多发一种二进制帧，届时不需要重新签字。
- **不做的部分要如实写进方案书**：分包回声消除与双讲抑制没做，实现的是"VAD 触发的半双工切换 + 播放端即时静音"。指南第 7.4 节明确禁止把简单静音检测说成完整双讲抗噪，第 12.1 节第 4 目也要求如实标注实现程度。

## 三、首字响应时延的口径（必须统一，否则数字没法比）

```
t0 = vad_end        用户最后一个有效音频帧，即"说完了"那一刻
t1 = play_first     浏览器第一块 TTS 音频真正开始播放
首字响应时延 = t1 − t0
```

三个分段偏移（都相对 t0），用来定位是哪一段拖慢：

| 分段 | 计算 | 含义 |
|---|---|---|
| ASR | `asr_final − vad_end` | 用户说完到文字出来 |
| LLM | `llm_first_token − vad_end` | 到模型吐出第一个 token |
| TTS | `tts_first_audio − vad_end` | 到第一块音频生成好 |

**不能混用的三个东西**（第 7.5 节点名禁止）：ASR 尾包延迟、LLM 首 token 延迟，都不是"出声了"。

**验收线**：P50 ≤ 2000 ms、P95 < 2500 ms，样本至少 20 通电话。达不到不许往下堆功能，先按第 7.5 节的六条手段调（全链路流式、按句切分、关思考模式、VAD 阈值 600→450 ms、就近选区、开场白预合成）。

## 四、工具怎么用

```bash
python -m eval.latency                      # 全部会话的 P50 / P95 / P99 与分段均值
python -m eval.latency --session S-20261114-001
python -m eval.latency --json               # 给看板、自测报告吃
python -m eval.latency --gate               # 按验收线判定，不达标退出码 1
```

输出长这样：

```
样本：2 轮 / 1 通电话（缺首播时点 0 条未计入）
注意：其中 2 轮来自探针脚本（假数据，只用于验证工具本身，不可作为验收证据）
首字响应时延  P50 1200.0 ms  P95 1200.0 ms  P99 1200.0 ms
分段均值（相对说完那一刻）  ASR 300.0 ms  LLM 700.0 ms  TTS 1000.0 ms
不通过：样本 2 轮全部来自探针脚本，不能作为验收证据
判定：未达标
```

**两道防自欺的闸**：

1. 会话号里带 `check`、`probe`、`test` 的，一律标记为探针数据；
2. 样本全部是探针时，`--gate` 直接判不通过，哪怕数字好看。

这条是照着第 9.6 节"官方明令不得伪造"和第 14 章"未硬编码任何测试答案"来的。假数据只能证明工具本身是通的，不能写进答辩材料。
